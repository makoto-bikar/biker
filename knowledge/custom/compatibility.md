# Parts Compatibility

## Purpose

このKnowledgeは、
オートバイのカスタムパーツ・交換部品の
適合性を判断するための共通ルールを定義する。

対象：

- パーツ適合確認
- 純正部品との互換性
- 社外パーツの取付可否
- ボルトオン / ポン付け
- 加工が必要なカスタム
- 追加部品
- 取付寸法
- クリアランス
- 電装適合
- ブレーキ適合
- サスペンション適合
- ホイール適合
- ハンドル適合
- マフラー適合
- 燃料系パーツ適合
- 駆動系パーツ適合

このファイルは、
「パーツが車両に適合するか」を判断するための
共通・汎用的な知識を扱う。

特定車種・年式・型式・世代ごとの
具体的な適合情報は、
車種別Knowledgeやメーカー資料を優先する。


# 1. Compatibility Basic Principle

パーツの適合判断では、

「物理的に取り付けられるか」

だけでは不十分。

最低でも以下を確認する。

- メーカー
- 車種
- 年式
- 型式
- 世代
- 純正 / 社外
- 取付方式
- 寸法
- 電気仕様
- 周辺部品との干渉
- 強度
- 機能
- 安全性
- 法規

「取り付けできる」ことと
「安全に使用できる」ことは同じではない。


# 2. Vehicle Identification

適合確認を行う前に、
対象車両をできるだけ正確に特定する。

確認項目：

1. メーカー
2. 車種
3. 年式
4. 型式
5. 世代
6. グレード
7. 純正状態
8. 現在のカスタム状態

Garageに車両情報が登録されている場合は、
その情報を優先する。

質問文に車種・年式・型式などが含まれている場合は、
Garage情報との整合性も確認する。

車両情報が不足している場合は、
適合を断定しない。


# 3. Part Identification

次に、
取り付けようとしているパーツを特定する。

確認項目：

- メーカー
- 商品名
- 型番
- 部品番号
- パーツカテゴリ
- 対応車種
- 対応年式
- 対応型式
- 寸法
- 取付方式

商品ページやメーカー資料に
適合車種が明記されている場合は、
その情報を優先する。

商品名だけでは適合を判断しない。


# 4. Compatibility Levels

パーツの適合状態は、
以下の5段階に分類する。


## Level 1: Direct Fit

純正取付位置・仕様に適合し、
基本的に追加加工なしで取り付けられる。

表現例：

「ボルトオンで取り付け可能と考えられる」

ただし、
実車状態や個体差による確認は必要。


## Level 2: Minor Modification

軽微な加工や追加部品が必要。

例：

- ステー変更
- スペーサー追加
- 配線加工
- ボルト変更
- 小規模な干渉対策

「ポン付け」とは表現しない。


## Level 3: Major Modification

大きな加工や複数部品の変更が必要。

例：

- フレーム加工
- マウント製作
- 大幅な配線変更
- ブレーキ系統変更
- サスペンション構造変更

安全性・強度・法規の確認が必要。


## Level 4: Not Compatible

構造・寸法・仕様などの理由で
適合しない。

この場合は、
なぜ適合しないのかを説明する。


## Level 5: Unknown

必要な情報が不足しており、
適合判断できない。

「たぶん付く」
などの推測で断定しない。


# 5. Physical Compatibility

物理的な適合では、
以下を確認する。

- 長さ
- 幅
- 高さ
- 直径
- 内径
- 外径
- ボルト径
- ボルト間隔
- 取付位置
- オフセット
- 穴位置
- ネジ規格
- スペーサー
- クリアランス

寸法が一致していても、
周辺部品との干渉があれば
使用できない場合がある。


# 6. Mounting Compatibility

取付方法を確認する。

代表例：

- ボルト固定
- クランプ固定
- フランジ固定
- 圧入
- ベアリング支持
- ステー固定
- 溶接
- 専用ブラケット

同じ部品カテゴリでも、
取付方式が違えば互換性がない場合がある。


# 7. Thread Compatibility

ボルトやナットを使用する部品では、

- ネジ径
- ネジピッチ
- 長さ
- ネジ規格
- 強度
- 座面

などを確認する。

「径が同じだから使える」
とは限らない。

ネジピッチが異なる場合、
無理に締め込まない。


# 8. Clearance

パーツ交換では、
周辺部品とのクリアランスを確認する。

確認対象：

- フレーム
- タンク
- フェンダー
- タイヤ
- ホイール
- ブレーキ
- フォーク
- スイングアーム
- チェーン
- ベルト
- マフラー
- エンジン
- 配線
- ホース

静止状態だけでなく、
以下の状態でも確認する。

- サスペンションが沈み込んだ状態
- ハンドルを左右いっぱいに切った状態
- ブレーキ操作時
- 駆動系が動作している状態

動作時に干渉する場合は、
適合とは判断しない。


# 9. Functional Compatibility

物理的に取り付けられても、
正常に機能するとは限らない。

確認項目：

- 電圧
- 電流
- 油圧
- 燃料供給
- 吸気
- 排気
- ブレーキ
- サスペンション
- 駆動系
- センサー
- ECU / CDI / TCI
- スイッチ

機能面に問題がある場合、
「取付可能」とだけ回答しない。


# 10. Electrical Compatibility

電装部品では、

- 電圧
- 消費電力
- 電流
- 極性
- コネクター
- 配線
- ヒューズ
- リレー
- アース

を確認する。

特に、

- LED
- ウインカー
- ヘッドライト
- テールランプ
- USB電源
- メーター
- ホーン

などでは電気仕様を確認する。

コネクターが合わない場合は、
配線加工が必要になる可能性がある。

ただし、
配線加工だけで安全に使用できるとは限らない。


# 11. Brake Compatibility

ブレーキ関連パーツでは、
特に慎重に適合を判断する。

確認項目：

- ディスク径
- ディスク厚
- キャリパー
- キャリパーマウント
- マスターシリンダー
- ブレーキホース
- アクスル
- ホイール
- パッド
- 油圧系統

ブレーキ性能や制動バランスに影響する変更は、
単純な「互換あり / なし」だけで判断しない。

不明な場合は専門店やメーカーへの確認を推奨する。


# 12. Suspension Compatibility

サスペンション関連では、

- 全長
- ストローク
- 取付径
- 取付幅
- 上下マウント
- スプリング特性
- 減衰特性
- 車高
- 周辺部品との干渉

を確認する。

同じ長さでも、
取付方法やストロークが違えば
適合しない場合がある。


# 13. Wheel and Tire Compatibility

ホイールでは、

- リム径
- リム幅
- アクスル径
- ハブ幅
- ベアリング
- スペーサー
- ブレーキディスク位置
- スプロケット位置
- オフセット

などを確認する。

タイヤでは、

- サイズ
- 荷重能力
- 速度記号
- リム適合
- フェンダーとのクリアランス
- チェーンとのクリアランス
- フレームとのクリアランス

などを確認する。


# 14. Handlebar Compatibility

ハンドルでは、

- ハンドル径
- クランプ径
- 幅
- 高さ
- プルバック
- スイッチ取付部
- グリップ
- レバー
- ケーブル長
- ブレーキホース
- 配線

を確認する。

ハンドルが物理的にクランプできても、

- ケーブルが届かない
- ホースが引っ張られる
- 配線が届かない
- タンクに干渉する

場合がある。


# 15. Exhaust Compatibility

マフラー・エキゾーストでは、

- エンジン側取付
- フランジ
- ボルト位置
- パイプ径
- マウント位置
- フレームとの干渉
- ステップとの干渉
- タイヤとの干渉
- ブレーキとの干渉
- 排気系センサー
- 排気ガス対策装置

などを確認する。

物理的に取り付けられても、
燃調・排気特性・法規に影響する場合がある。


# 16. Fuel System Compatibility

燃料系パーツでは、

- 燃料方式
- キャブレター / FI
- 燃料圧
- ホース径
- 取付方式
- 燃料ポンプ
- インジェクター
- タンク
- 燃料コック

などを確認する。

キャブレター車とFI車では、
燃料供給システムが大きく異なる。

そのため、
見た目やサイズだけで互換性を判断しない。


# 17. Drivetrain Compatibility

駆動系では、

- チェーンサイズ
- スプロケット丁数
- スプロケット取付
- オフセット
- チェーンライン
- ベルトサイズ
- プーリー
- 駆動方式

などを確認する。

スプロケット変更では、
チェーン長さや周辺部品への干渉も確認する。


# 18. Engine Compatibility

エンジン関連部品では、

- エンジン型式
- 世代
- 取付位置
- ボルト位置
- センサー
- 配線
- 吸気
- 排気
- 燃料供給
- 点火
- ECU / CDI / TCI

などを確認する。

同じ車種名でも
年式や世代によって仕様が異なる場合がある。

世代違いの部品を
「同じ車種だから使える」
と判断しない。


# 19. Generation Compatibility

同一車種でも、
世代変更によって部品互換性が変わる場合がある。

確認する情報：

- 年式
- 型式
- モデルコード
- 世代
- 部品番号
- メーカー適合表

特に、

- エンジン
- キャブレター
- FI
- 電装
- ブレーキ
- フォーク
- ホイール
- メーター

などは世代差に注意する。


# 20. OEM and Aftermarket Parts

純正部品と社外部品では、
適合情報の確認方法が異なる。

純正部品：

- メーカー部品番号
- 純正パーツリスト
- サービスマニュアル

などを優先する。

社外部品：

- メーカー公式適合表
- 商品説明
- 取付説明書
- 型番
- 実測寸法

などを確認する。

販売ページの「汎用品」という表記だけでは、
車種への適合を断定しない。


# 21. Bolt-On vs Universal

「ボルトオン」と「汎用品」は
同じ意味ではない。

ボルトオン：

特定車種への適合を前提として、
基本的に追加加工なしで取り付けられる部品。

汎用品：

複数の車両に使用できるよう設計された部品。

汎用品の場合、
車種ごとに

- ステー
- ボルト
- 配線
- ホース
- スペーサー
- 加工

などが必要になる場合がある。


# 22. Required Additional Parts

パーツ単体では使用できず、
追加部品が必要になる場合がある。

例：

- ステー
- スペーサー
- ボルト
- ナット
- ワッシャー
- 配線
- コネクター
- リレー
- ヒューズ
- ホース
- ケーブル
- ブラケット

回答では、
「本体以外に必要なもの」が分かる場合は
明示する。


# 23. Installation Compatibility

取付可能かどうかだけでなく、
取付後の状態も確認する。

確認項目：

- 操作できるか
- 正常に動くか
- 干渉しないか
- 配線が安全か
- ホースが安全か
- 熱害がないか
- 振動に耐えられるか
- 強度が確保されているか
- メンテナンスできるか


# 24. Modification Risk

加工を伴う場合は、
加工内容によってリスクを分類する。


## 比較的軽微な加工

例：

- 小さなステー加工
- 配線延長
- スペーサー追加


## 高リスクな加工

例：

- フレーム切断
- フレーム溶接
- ステム加工
- ブレーキ取付部加工
- サスペンション取付部加工
- ホイール加工

高リスクな加工については、
DIYを安易に推奨しない。


# 25. Compatibility Decision Process

適合判断は以下の順番で行う。

1. 車両を特定
2. パーツを特定
3. メーカー適合情報を確認
4. 年式・型式・世代を確認
5. 取付方式を確認
6. 寸法を確認
7. 周辺部品との干渉を確認
8. 機能面を確認
9. 安全性を確認
10. 法規を確認
11. 適合レベルを判定

情報が不足している場合は、
その段階で「Unknown」とする。


# 26. Compatibility Answer Format

適合確認の回答では、
可能な限り以下の形式を使用する。

【適合判定】
Direct Fit / Minor Modification /
Major Modification / Not Compatible / Unknown

【理由】
適合・不適合の理由

【確認が必要な項目】
必要な寸法・型式・部品番号など

【追加で必要な部品】
必要な場合のみ記載

【注意点】
干渉・安全性・法規など

【確実にするために必要な情報】
不足している情報


# 27. Evidence Priority

適合判断では、
以下の情報を優先する。

1. メーカー公式適合表
2. メーカー取付説明書
3. 純正パーツリスト
4. サービスマニュアル
5. メーカー公式商品情報
6. 信頼できる販売元の適合情報
7. 実測情報
8. ユーザー報告・コミュニティ情報

情報源によって内容が異なる場合は、
より信頼性の高い一次情報を優先する。


# 28. Do Not Guess

以下のような推測は禁止する。

- 「同じ車種だから付く」
- 「たぶんポン付け」
- 「サイズが同じだから大丈夫」
- 「他の人が付けているから大丈夫」
- 「見た感じ同じだから使える」

適合を確認できない場合は、
Unknownとして扱う。


# 29. Safety

以下の部品は、
適合判断を特に慎重に行う。

- ブレーキ
- ステアリング
- フレーム
- サスペンション
- ホイール
- タイヤ
- 駆動系
- 燃料系
- 電装系

安全に関係する部品では、
不確かな情報だけで
「取り付け可能」と断定しない。

必要に応じて、

- メーカー
- 正規販売店
- 専門店
- 整備士

への確認を推奨する。


# 30. Legal and Inspection Considerations

パーツ交換や加工によって、

- 車体寸法
- 灯火類
- 排気
- 騒音
- ブレーキ
- タイヤ
- フレーム
- サスペンション
- 構造

などが変化する場合、
法規や車検に影響する可能性がある。

具体的な法規については、
regulations/ 以下のKnowledgeを優先する。

法規が不明な場合、
「合法」と断定しない。

# 32. Knowledge Priority

適合判断では、
以下の優先順位でKnowledgeを使用する。

1. 車種・世代別のメーカー資料・サービスマニュアル
2. メーカー公式適合情報

8. regulations/ 以下

車種固有の情報と一般論が異なる場合、
車種固有の資料を優先する。


# 33. Uncertainty Rules

以下の情報が不足している場合、
適合を断定しない。

不足情報の例：

- メーカー
- 車種
- 年式
- 型式
- 世代
- パーツメーカー
- 商品名
- 型番
- 部品番号
- 寸法
- 現在のカスタム状態

必要な情報が不足している場合は、
ユーザーに追加情報を確認する。

例：

「車種と年式は分かりますが、
パーツの型番が分からないため、
現時点では適合を確定できません。」


# 34. Important Principle

パーツ適合の判断では、

「取り付けできる」

と

「安全に使用できる」

を分けて考える。

さらに、

「安全に使用できる」

と

「公道で合法的に使用できる」

も分けて考える。

Bikarは、
この3つを混同しない。


# 35. Scope

このKnowledgeは、
オートバイのパーツ適合性を判断するための
共通ルールを扱う。

以下の具体的な情報は、
このファイルだけでは断定しない：

- 特定車種への適合
- 特定年式への適合
- 特定型式への適合
- 特定部品番号の互換性
- 特定商品のボルトオン可否
- 具体的な取付寸法
- 締付トルク
- 電圧・電流の具体値
- ブレーキ仕様
- サスペンション仕様
- 法規の具体的数値

これらは、
車種・世代別Knowledge、
メーカー資料、
関連Knowledge、
regulations/ 以下のKnowledgeを参照する。
