# Handlebars

## Purpose

このKnowledgeは、
オートバイのハンドルカスタムに関する
共通・汎用的な知識を定義する。

対象：

- ハンドル交換
- ハンドル形状
- ハンドル幅
- ハンドル高さ
- プルバック
- クランプ径
- グリップ位置
- スイッチ類
- レバー
- ケーブル
- ブレーキホース
- 配線
- ハンドルポジション
- ハンドル周辺のクリアランス
- ハンドルカスタムの安全性
- ハンドルカスタムの適合性

このファイルは車種共通のカスタム知識を扱う。

車種・年式・型式ごとの具体的な純正ハンドル仕様、
クランプ径、ケーブル長、ブレーキホース長、
取付寸法などは、
車種・世代別Knowledgeやメーカー資料を優先する。


# 1. Handlebar Overview

ハンドルは、
ライダーが車両の方向や操作を入力するための重要な部品。

主な役割：

- ステアリング操作
- ライディングポジションの調整
- スイッチ操作
- ブレーキ操作
- クラッチ操作
- スロットル操作

ハンドル形状を変更すると、
見た目だけでなく、

- 操作性
- 姿勢
- 肩や腕への負担
- ケーブル取り回し
- ブレーキホース
- 配線
- ステアリング特性

などにも影響する。


# 2. Handlebar Types

代表的なハンドル形状：

- フラットバー
- ドラッグバー
- コンチネンタルハンドル
- クラブマンバー
- セパレートハンドル
- エイプハンガー
- Zバー
- トラッカーバー
- スーパーバー
- チョッパーバー

ハンドル名称や形状は
メーカーによって異なる場合がある。

名前だけで判断せず、
実際の寸法や形状を確認する。


# 3. Handlebar Dimensions

ハンドルの主な寸法：

- 全幅
- 全高
- プルバック
- クランプ部幅
- クランプ径
- グリップ径
- グリップ位置
- スイッチ取付部

同じ「ドラッグバー」などの名称でも、
寸法が違えばポジションや適合性が変わる。


# 4. Clamp Diameter

ハンドル交換では、
ハンドルバー径とクランプ径の適合を確認する。

確認項目：

- ハンドル径
- クランプ側径
- クランプ幅
- クランプ方式
- メーカー指定サイズ

径が合わない場合は、
そのまま取り付けない。

変換カラーなどが使用できる場合でも、
適切な部品であることを確認する。


# 5. Handlebar Width

ハンドル幅は、
操作性や車体寸法に影響する。

幅が広い場合：

- 操作時のレバー比に影響する可能性がある
- 肩や腕の姿勢が変化する
- 車体の取り回しが変化する

幅が狭い場合：

- 取り回しや姿勢が変化する
- ステアリング操作の感覚が変化する

ハンドル幅を変更する場合は、
車体寸法や法規への影響も確認する。


# 6. Handlebar Height

ハンドル高さは、
ライダーの上半身の姿勢に影響する。

高くすると：

- 上体が起きる
- 腕の位置が高くなる
- ケーブル類の長さが不足する可能性がある

低くすると：

- 上体が前傾する
- ケーブルの取り回しが変化する
- タンクなどとの干渉が発生する可能性がある

実際のポジションは、
シート・ステップ・ハンドルの組み合わせで決まる。


# 7. Pullback

プルバックは、
ハンドルがライダー側へどの程度後方に位置するかを表す要素。

プルバックが大きくなると、
グリップ位置がライダーに近づく。

これによって、

- 肘の角度
- 肩の位置
- 上半身の姿勢
- ステアリング操作感

などが変化する。


# 8. Handlebar Position

ハンドルの回転角度や取付位置を変更すると、
ライディングポジションが変わる。

確認項目：

- グリップ位置
- レバー角度
- スイッチ位置
- タンクとの距離
- ケーブルの余裕
- ブレーキホース
- 配線

左右いっぱいにハンドルを切った状態でも、
各ケーブル・ホース・配線が無理なく動くことを確認する。


# 9. Controls

ハンドルには、

- スロットル
- ブレーキレバー
- クラッチレバー
- スイッチボックス
- ミラー

などが取り付けられる。

ハンドル交換時は、
これらの部品が正しく取り付けられるか確認する。


# 10. Throttle

スロットルは、
エンジン出力を操作する重要な部品。

ハンドル交換後は、

- スロットルの動作
- ケーブル取り回し
- ケーブルの張り
- ハンドルを左右に切った状態での動作
- スロットルが自然に戻るか

を確認する。

ハンドルを左右に切ったときに
スロットル操作が重くなったり、
自然に戻らなくなったりする場合は、
その状態で走行しない。


# 11. Brake Lever

ブレーキレバーは、
フロントブレーキを操作するための部品。

ハンドル交換時は、

- レバー取付径
- マスターシリンダー
- レバー角度
- ブレーキホース
- スイッチ
- 周辺部品との干渉

を確認する。

ブレーキ操作に違和感がある場合は、
走行前に原因を確認する。


# 12. Clutch Lever

クラッチレバーは、
クラッチ操作を行う。

ハンドル交換時は、

- クラッチレバー取付部
- クラッチワイヤー
- ワイヤー取り回し
- ワイヤー長
- レバー角度
- 操作感

を確認する。

油圧クラッチの場合は、
油圧ホースやマスターシリンダーとの適合も確認する。


# 13. Cables

ハンドル形状を変更すると、
ケーブルの必要長さが変わる場合がある。

対象：

- スロットルケーブル
- クラッチケーブル
- チョークケーブル
- その他の操作ケーブル

確認すること：

- 長さ
- 取り回し
- 曲げ
- 引っ張り
- 潰れ
- ハンドル操作との干渉

長すぎても短すぎても問題になる可能性がある。


# 14. Brake Hose

ハンドル交換では、
ブレーキホースの長さや取り回しが重要。

確認項目：

- ホース長
- フィッティング
- 取り回し
- 曲げ
- 引っ張り
- フォークとの干渉
- ハンドル操作時の余裕

左右いっぱいにハンドルを切った状態でも、
ホースが引っ張られないことを確認する。

ブレーキホースの加工や交換は、
ブレーキ性能に直接関係するため慎重に行う。


# 15. Wiring

ハンドル周辺には、
スイッチ類の配線が通っている。

ハンドル交換時は、

- 配線長
- 配線取り回し
- コネクター
- スイッチ位置
- ハンドル内部への配線
- 挟み込み
- 引っ張り

などを確認する。

配線を無理に引っ張った状態で固定しない。


# 16. Mirror

ハンドル交換では、
ミラーの取付位置も変化する場合がある。

確認項目：

- ミラー取付ネジ
- 左右の仕様
- 視認性
- ハンドル幅
- レバーとの干渉
- タンクとの干渉

ミラーを変更する場合は、
法規上の要件も確認する。


# 17. Tank Clearance

ハンドルを左右いっぱいに切ったときに、

- タンク
- メーター
- フレーム
- スイッチ
- レバー
- ケーブル

などへ干渉しないことを確認する。

特にハンドルを高くしたり、
プルバックを大きくしたりした場合は、
干渉位置が変化する可能性がある。


# 18. Steering Clearance

ハンドルを左右いっぱいに切った状態で、

- ケーブル
- ブレーキホース
- 配線
- タンク
- フレーム
- フォーク
- メーター

などとの干渉を確認する。

ハンドルストッパーなど、
車両のステアリング機構を意図せず変更しない。


# 19. Handlebar Customization

代表的なカスタム：

- ドラッグバー
- エイプハンガー
- Zバー
- フラットバー
- クラブマンバー
- チョッパーバー
- ハンドルカット
- ハンドル交換
- ハンドルポジション変更

カスタムでは、

- 見た目
- ポジション
- 操作性
- ケーブル
- ホース
- 配線
- クリアランス
- 法規

をまとめて確認する。


# 20. Handlebar Cutting

ハンドルをカットして幅を変更する場合、
以下を確認する。

- 切断位置
- 左右の長さ
- スイッチ位置
- グリップ位置
- レバー位置
- ミラー
- 強度
- 仕上げ

左右非対称にならないよう注意する。

また、
切断によってメーカーが想定した
強度や構造が変わる可能性がある。

加工後の安全性を確認する。


# 21. Cable Routing

ケーブル類は、
急激な曲げや引っ張りを避ける。

適切な取り回しでは、

- ハンドルを左へ切る
- ハンドルを右へ切る
- サスペンションが作動する

などの状態を確認する。

どの位置でも、

- ケーブルが張らない
- ケーブルが潰れない
- ケーブルが擦れない
- ケーブルが他部品へ干渉しない

ことを確認する。


# 22. Handlebar Installation

基本的な取付確認：

1. 車種・型式を確認
2. ハンドル適合を確認
3. クランプ径を確認
4. ハンドルを仮組み
5. ポジションを調整
6. スイッチ類を取り付ける
7. ケーブルを取り回す
8. ブレーキホースを確認
9. 配線を確認
10. 左右へハンドルを切る
11. 干渉を確認
12. 操作系を確認
13. 指定トルクで固定
14. 再度動作確認

具体的な締付トルクは
車種・部品メーカー指定値を優先する。


# 23. Compatibility

ハンドル適合では、

- 車種
- 年式
- 型式
- 世代
- クランプ径
- クランプ幅
- ハンドル径
- スイッチ取付
- ケーブル
- ブレーキホース
- 配線
- ミラー
- タンククリアランス

を確認する。

「ハンドル径が合う」
だけでは適合を確定しない。


# 24. Compatibility Levels

ハンドル交換の適合状態は、
以下の5段階で判断する。

## Direct Fit

基本的に追加加工なしで取り付け可能。

## Minor Modification

軽微な加工や追加部品が必要。

例：

- ケーブル変更
- 配線延長
- スペーサー
- ステー

## Major Modification

大きな加工や複数部品の変更が必要。

例：

- 大幅なケーブル変更
- ブレーキ系統変更
- ハンドルマウント変更
- 大規模な配線加工

## Not Compatible

寸法・構造・仕様などから適合しない。

## Unknown

必要な情報が不足しており、
適合を判断できない。


# 25. Handlebar Diagnosis

## 症状：ハンドルを切るとスロットルが重くなる

確認項目：

- スロットルケーブル
- ケーブル取り回し
- ケーブル長
- ハンドル角度
- ケーブルの引っ張り

異常がある場合は、
その状態で走行しない。


## 症状：ハンドルを切るとブレーキホースが張る

確認項目：

- ブレーキホース長
- 取り回し
- フィッティング
- ハンドル高さ
- ハンドル角度

必要に応じて適切な長さのホースへ変更する。


## 症状：ハンドルを切ると配線が引っ張られる

確認項目：

- 配線長
- 配線ルート
- コネクター
- ハンドル高さ
- スイッチ位置


## 症状：ハンドルがタンクに当たる

確認項目：

- ハンドル幅
- 高さ
- プルバック
- ハンドル角度
- ステアリングストッパー
- タンク形状


# 26. Riding Position

ハンドル形状によって、
ライダーの姿勢が変化する。

確認する要素：

- 肩
- 肘
- 手首
- 背中
- 腰
- 足
- シート

ハンドルだけでなく、
シート・ステップとの位置関係を考える。

見た目を優先しすぎると、
長時間走行時の疲労につながる場合がある。


# 27. Chopper Customization

チョッパースタイルでは、

- 高いハンドル
- 独特なプルバック
- ロングフォーク
- シート
- ステップ

などを組み合わせることがある。

ただし、
ハンドルだけを変更しても
車体全体のスタイルやポジションが
最適になるとは限らない。

特にロングフォークなどと組み合わせる場合は、

- ステアリング
- ケーブル
- ブレーキホース
- 配線
- 車体ジオメトリー

まで確認する。


# 28. Safety

ハンドルはステアリング操作に直接関係するため、
重要保安部品に関係する作業として慎重に扱う。

作業後は必ず、

- ハンドル固定
- クランプ
- スロットル
- ブレーキ
- クラッチ
- スイッチ
- ミラー
- ケーブル
- ブレーキホース
- 配線
- タンクとの干渉
- 左右フルロック時の状態

を確認する。

特に、

「ハンドルを左右いっぱいに切った状態」

で操作系が正常に動作することを確認する。


# 29. Legal and Inspection Considerations

ハンドル変更では、

- 車体寸法
- ハンドル幅
- ミラー
- 操作装置
- ブレーキ
- ケーブル
- ステアリング

などが法規や車検に関係する場合がある。

具体的な法規については、
regulations/ 以下のKnowledgeを優先する。

法規が不明な場合、
「合法」と断定しない。

# 32. Uncertainty Rules

以下の情報が不足している場合、
適合や具体的な取付方法を断定しない。

不足情報の例：

- メーカー
- 車種
- 年式
- 型式
- 世代
- ハンドルメーカー
- 商品名
- 型番
- クランプ径
- ハンドル径
- 寸法
- 現在のカスタム状態

不明な場合は、

- 確認が必要
- 車種・型式が必要
- パーツ型番が必要
- 寸法確認が必要
- メーカー適合表の確認が必要

などと明示する。


# 33. Important Principle

ハンドルカスタムでは、

「ハンドルが付く」

だけでは完成ではない。

必ず、

- 操作性
- ケーブル
- ブレーキホース
- 配線
- クリアランス
- ステアリング
- ポジション
- 安全性
- 法規

まで確認する。

特に、
スロットル・ブレーキ・クラッチなどの操作系に
異常がある場合は走行しない。
