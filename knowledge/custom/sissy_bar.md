# Sissy Bar

## Purpose

シーシーバー（Sissy Bar）は、バイクのリア側に取り付ける縦方向のバー状パーツ。

主に以下の用途で使用される。

- ライダーやパッセンジャーの背もたれ・身体の保持
- 荷物やバッグの固定
- リアフェンダーの支持
- バイクのリア周りのスタイル形成
- カスタムデザインのアクセント

シーシーバーはチョッパーだけのパーツではない。

クルーザー、アメリカン、ボバー、カスタムバイク、ツーリング系など、
様々なスタイルのバイクで使用される。

特にカスタムバイクでは、
単なる実用品ではなく車体全体のシルエットを決める重要なパーツになる。


# 1. シーシーバーの名前

## Sissy Bar

英語では一般的に「Sissy Bar」と呼ばれる。

また、

- Sister Bar
- Passenger Backrest
- Backrest

などの名称で呼ばれる場合もある。

日本では一般的に、

- シーシーバー
- シシーバー
- シーシーバ
- シシーバ
- Sissy Bar
- Sissybar

など複数の表記が使われる。

BIKER AIでは、
これらを同じパーツとして認識する。


# 2. シーシーバーの由来

## 正確な起源について

シーシーバーが「誰によって、何年に発明されたか」を示す確実な単一の起源は確認されていない。

古いカスタムバイクやモーターサイクルの写真から、
1950年代にはリアフェンダー後方に取り付けられた小型のバー状構造が存在していたことが確認されている。

その後、1960年代から1970年代にかけて、
アメリカのカスタムバイク文化やチョッパー文化の発展とともに、
シーシーバーは広く知られるようになった。


## 初期の役割

初期のシーシーバーは、
現在のような派手なカスタムパーツというよりも、
主に乗員の身体を後方へ抜け落ちにくくするための保持装置や、
背もたれとしての役割を持っていた。

また、荷物を固定するための支点としても利用された。

つまり、

「見た目のためのパーツ」

として始まったものではなく、

「乗員を支える」
「荷物を支える」

という実用的な目的が重要だった。


# 3. 1960〜1970年代とチョッパー文化

1960年代から1970年代にかけて、
アメリカではカスタムバイクとチョッパー文化が大きく発展した。

この時代には、
純正状態のバイクを大きく変更し、
オーナー独自のスタイルを作るカスタムが広がった。

その中でシーシーバーも、
単純な背もたれ・保持装置から、
バイクの外観を構成するカスタムパーツへと変化していった。

特にチョッパーでは、
非常に高いシーシーバーを取り付けるスタイルが登場した。

シーシーバーを高くすることで、
バイクのリア側に強い縦方向のラインが生まれ、
チョッパー独特のシルエットを作ることができる。


# 4. 「Sissy」という名前の由来

「Sissy」という言葉の正確な語源については、
複数の説が存在する。

よく知られている説の一つとして、
パッセンジャーを支えるためのバーを、
「弱々しい」「臆病者」を意味するニュアンスのある
"sissy" と呼んだという説明がある。

また、
1960年代以降に安全装備やパッセンジャー保持装置が求められるようになったことに対する、
バイカー側の皮肉・揶揄から名称が広まったという説もある。

ただし、
これらを唯一確定した語源として扱わない。

BIKER AIでは、

「シーシーバーという名前の由来には諸説あり、
正確な起源は断定できない」

と説明する。


# 5. 1970年代以降のシーシーバー

1970年代には、
シーシーバーはカスタムバイクの象徴的なパーツの一つになった。

高さや形状を大きく変更したものが登場し、

- 非常に高いシーシーバー
- 曲げ加工されたシーシーバー
- 複雑なデザイン
- 装飾を施したシーシーバー
- ワンオフ製作されたシーシーバー

など、
デザイン性の高いものが増えていった。

この頃から、
シーシーバーは単なる背もたれではなく、

「バイクをどのようなスタイルにするか」

を表現するパーツとしての意味を強めていった。


# 6. 特許から見るシーシーバー

1975年には、
米国で「Sissy bar for a motorcycle」という名称の特許出願が行われている。

この特許では、
シーシーバーをバイク後方に配置し、
ライダーまたはパッセンジャーの背もたれとして利用できる構造が説明されている。

さらに、
背もたれ部分を移動させることで、
ライダー用・パッセンジャー用として位置を変更できる構造も考案されている。

このことからも、
1970年代半ばには「sissy bar」という名称と、
背もたれ・乗員保持装置としての構造がすでに確立していたことが分かる。

ただし、
この特許をシーシーバーそのものの発明年と判断してはいけない。

それ以前からシーシーバーと呼ばれる構造や類似構造が存在していたため、
この特許は「シーシーバーという名称・構造が1970年代にすでに確立していたことを示す資料」
として扱う。


# 7. 現代のシーシーバー

現在のシーシーバーは、
大きく以下の目的で使用される。

1. パッセンジャーの背もたれ
2. 荷物固定
3. リアフェンダー支持
4. カスタムスタイルの形成
5. デザインアクセント

製品によっては、

- 背もたれパッド
- キャリア
- バッグマウント
- クイックリリース機構

などが組み合わされている。


# 8. シーシーバーの基本構造

一般的なシーシーバーは、
以下の部品から構成される。

- シーシーバー本体
- 左右のマウント部
- ボルト・ナット
- フェンダーストラットとの接続部
- 必要に応じてバックレストパッド
- 必要に応じて荷物固定用マウント

製品によって構造は異なる。


# 9. 取り付け位置

シーシーバーは主にバイクのリア周辺に取り付けられる。

代表的な取り付け位置：

- リアフェンダーストラット
- リアフェンダー周辺
- フレーム後部
- 専用ブラケット

ただし、
車種や製品によって取り付け方法は大きく異なる。

「シーシーバーだから必ずフェンダーストラットに付く」
とは限らない。


# 10. シーシーバーの種類

## ロータイプ

比較的高さの低いシーシーバー。

特徴：

- リア周りをすっきり見せやすい
- 控えめなカスタムに向いている
- 日常使用しやすい
- 車体のシルエットを大きく変えにくい


## ミドルタイプ

中程度の高さを持つタイプ。

特徴：

- スタイルと実用性のバランスが良い
- 荷物固定に利用しやすい
- カスタム感を出しやすい


## ハイタイプ

高さのあるシーシーバー。

特徴：

- 強いカスタム感を出せる
- チョッパーとの相性が良い
- 車体後方の縦方向のラインが強くなる
- バイク全体のシルエットを大きく変える

高さが増えるほど、
取り付け強度や周辺部品との干渉を慎重に確認する必要がある。


# 11. シーシーバーの形状

## ストレート

直線を中心とした形状。

特徴：

- シンプル
- 無骨
- チョッパーと相性が良い
- ワンオフ製作にも向いている


## ラウンド

丸みを持った形状。

特徴：

- クラシックな雰囲気
- ビンテージ系カスタムと相性が良い


## アングル

複数の角度を組み合わせた形状。

特徴：

- 現代的
- シャープ
- 車体のデザインに合わせやすい


## ワンオフ

車体に合わせて製作するタイプ。

特徴：

- 自由度が非常に高い
- 独自のデザインを作れる
- 車体に合わせて高さ・角度・幅を設定できる
- 製作には溶接や金属加工が必要になる場合がある


# 12. シーシーバーの高さ

高さはシーシーバーを選ぶ際の重要な要素。

高さによってバイク全体の印象が大きく変わる。

## 低い

- 控えめ
- スッキリ
- 実用的
- 純正に近い雰囲気を残しやすい


## 中程度

- カスタム感が出る
- 実用性とデザインのバランスが良い


## 高い

- チョッパーらしい
- 強い存在感
- リアの縦ラインが強くなる
- 車体全体のシルエットが大きく変わる


# 13. 高さだけで決めない

シーシーバーの高さは、
単体で決めるのではなく、
バイク全体のバランスで考える。

確認するもの：

- フロントフォーク
- ハンドル
- タンク
- シート
- リアフェンダー
- リアショック
- タイヤ
- テールランプ
- ウインカー

例えば、

ロングフォーク
＋
高いハンドル
＋
高いシーシーバー

という組み合わせでは、
縦方向のラインを強くすることができる。

一方で、
低いハンドル
＋
短いフォーク
＋
非常に高いシーシーバー

では、
シーシーバーだけが極端に目立つ可能性がある。


# 14. シーシーバーとチョッパー

シーシーバーはチョッパーとの相性が非常に良い。

チョッパーでは、

- ロングフォーク
- エイプハンガー
- 小型タンク
- ソロシート
- 高いシーシーバー
- 細身のタイヤ
- ロング＆ローな車体構成

などを組み合わせることで、
独特のシルエットを作ることができる。

ただし、

「シーシーバーを付ければチョッパーになる」

わけではない。

シーシーバーはあくまで車体全体のスタイルを構成する一要素。


# 15. シーシーバーとボバー

シーシーバーはボバースタイルでも使用できる。

ただし、
チョッパーのような非常に高いタイプではなく、
比較的低い・シンプルなシーシーバーを使用すると、
ボバーのシンプルな外観を維持しやすい。

ボバーでは、

- シンプルなシーシーバー
- 小型のリア周り
- ソロシート
- シンプルなフェンダー

などとの組み合わせが考えられる。


# 16. シーシーバーとクルーザー

クルーザーでは、
シーシーバーは非常に実用的なパーツとしても使用される。

主な目的：

- パッセンジャーの背もたれ
- 荷物固定
- ツーリング時の荷物保持
- リアフェンダー周辺のアクセサリー取り付け

デザインよりも実用性を重視した製品も多い。


# 17. 荷物固定

シーシーバーは荷物を固定するための支点として利用できる。

使用例：

- サイドバッグ
- ロールバッグ
- ツーリングバッグ
- バックパック
- 荷締めベルト

ただし、
シーシーバーなら何でも荷物固定に使用できるわけではない。

製品の強度・固定方法・メーカーの使用条件を確認する。


# 18. 荷物固定時の注意

荷物を固定する場合は以下を確認する。

- タイヤに接触しない
- チェーンに接触しない
- ベルトがチェーンに巻き込まれない
- マフラーに接触しない
- テールランプを隠さない
- ウインカーを隠さない
- ナンバープレートを隠さない
- ライダーの操作を妨げない
- 荷物が脱落しない
- サスペンション作動時にも干渉しない

特に長いシーシーバーでは、
荷物の固定位置によって車体後方への張り出しが大きくなる。


# 19. タンデム用途

シーシーバーはパッセンジャーの背もたれとして利用できる。

ただし、

「シーシーバーが付いている＝タンデム可能」

ではない。

タンデム用途では、

- シーシーバーの強度
- マウント部の強度
- タンデムシート
- タンデムステップ
- 車体側の仕様
- 製品メーカーの使用条件

などを確認する。

シーシーバー自体が背もたれとして設計されているか、
単なるスタイル用バーなのかも確認する。


# 20. バックレストパッド

シーシーバーには、
バックレストパッドを取り付けられる場合がある。

バックレストパッドの目的：

- 背中を支える
- 長距離走行時の快適性を高める
- パッセンジャーの身体を支える

取り付け可能かどうかは、
シーシーバーの形状・幅・メーカーによって異なる。


# 21. クイックリリースタイプ

シーシーバーには、
工具を使わずに取り外しやすいクイックリリースタイプも存在する。

メリット：

- 必要なときだけ装着できる
- カスタムスタイルを切り替えやすい
- ツーリング時だけ使用できる

デメリット：

- マウント機構が複雑になる場合がある
- 固定状態を毎回確認する必要がある


# 22. リアフェンダーとの関係

シーシーバーを取り付ける場合、
リアフェンダーとの位置関係が重要。

確認するもの：

- フェンダー幅
- フェンダー形状
- フェンダーストラット
- 取り付け穴
- ボルト位置
- タイヤとのクリアランス
- シートとの位置関係

リアフェンダーを交換する場合は、
シーシーバーとの適合も同時に考える。


# 23. サスペンションとの関係

リアサスペンションが作動すると、
タイヤとフェンダーなどの位置関係が変化する。

そのため、
静止状態で干渉していなくても、
サスペンションが沈み込んだ際に干渉する可能性がある。

確認するもの：

- タイヤとシーシーバーの距離
- フェンダーとシーシーバーの位置
- ボルトやステーの突出
- 配線
- テールランプ
- ウインカー

取り付け後は、
実際のサスペンション作動範囲を考慮して確認する。


# 24. タイヤとのクリアランス

シーシーバーの下部や取り付け部が、
タイヤに近すぎないことを確認する。

特に、

- ローダウン
- ロングショック
- ショートショック
- タイヤサイズ変更
- フェンダー変更

などを行った車体では、
純正状態とクリアランスが変化する。

「車種専用品だから絶対に干渉しない」
と判断せず、
現在の車体仕様を確認する。


# 25. ウインカーとの関係

シーシーバーを取り付けると、
ウインカーの位置と干渉する場合がある。

確認するもの：

- ウインカー位置
- ウインカーステー
- シーシーバーの幅
- 荷物を積んだ場合の視認性

ウインカーを移設する場合は、
電装KnowledgeおよびLighting Knowledge、
必要に応じてRegulations Knowledgeも参照する。


# 26. テールランプとの関係

シーシーバーの形状によっては、
テールランプやナンバー周辺の配置変更が必要になる場合がある。

特にリアフェンダーを変更する場合は、

- テールランプ
- ナンバー灯
- ウインカー
- ナンバープレート

の位置関係をまとめて考える。


# 27. ボルトオン

ボルトオンタイプは、
車体側の既存の取り付け位置を利用して装着するタイプ。

メリット：

- 加工を減らせる
- DIYしやすい
- 純正状態へ戻しやすい場合がある

ただし、
「ボルトオン」と書かれていても、
現在の車体が純正状態であることを前提としている場合がある。

カスタム済み車両では、
追加加工や別部品が必要になる場合がある。


# 28. 加工取り付け

ワンオフや汎用品では、
加工が必要になる場合がある。

例：

- ステー製作
- 穴あけ
- ブラケット製作
- 曲げ加工
- 溶接
- フェンダー加工

加工が必要な場合は、
車体強度や取り付け剛性に関わるため、
初心者が無理に行わない。


# 29. ワンオフシーシーバー

ワンオフでは、

- 高さ
- 幅
- 角度
- 曲げ
- 材料
- 太さ
- マウント位置
- デザイン

を自由に設定できる。

そのため、
既製品では作れない独自のシルエットを作れる。

ただし、
溶接・金属加工・強度設計が必要になる場合がある。

乗員保持や荷物固定に使用する場合は、
見た目だけでなく十分な強度を確保する必要がある。


# 30. シーシーバーの素材

一般的には金属製。

代表例：

- スチール
- ステンレス
- その他金属

スチール製では、
表面処理として

- クロームメッキ
- 塗装
- パウダーコート

などが使用される場合がある。

素材や表面処理によって、

- 強度
- 重量
- 耐食性
- 見た目
- メンテナンス性

が変わる。


# 31. デザインとしてのシーシーバー

シーシーバーは、
リア側に大きな縦ラインを作るパーツ。

そのため、
以下の要素とのバランスが重要。

- フォーク
- ハンドル
- タンク
- シート
- フェンダー
- タイヤ
- マフラー

特にチョッパーでは、
シーシーバーの高さとフロントフォークの長さのバランスによって、
車体全体の印象が大きく変化する。


# 32. シーシーバーを選ぶ手順

ユーザーがシーシーバーを選ぶ場合は、
以下の順番で確認する。

1. 車種
2. 年式
3. 現在のカスタム状態
4. リアフェンダー
5. フェンダーストラット
6. 取り付け方式
7. ボルト径
8. ボルト間隔
9. シーシーバーの幅
10. 高さ
11. 角度
12. 使用目的
13. バッグなどの積載予定
14. タンデム用途
15. 周辺部品との干渉
16. 必要な工具
17. 加工の有無
18. 安全性
19. 法規への影響


# 33. SR400で考える場合

SR400にシーシーバーを取り付ける場合は、
単純に「SR400用」という情報だけで判断しない。

確認するもの：

- 年式
- リアフェンダー
- フェンダーストラット
- シート
- リアショック
- テールランプ
- ウインカー
- ナンバープレート位置
- 現在のカスタム状態

特にチョッパーカスタムでは、
純正状態からリア周りを変更していることがあるため、
市販品の適合条件と実車の状態を照合する。


# 34. 国産アメリカンで考える場合

国産アメリカンでは、
車種ごとにリアフェンダーやストラット、
シート構造などが異なる。

そのため、

- メーカー
- 車種
- 年式
- グレード
- 現在のリア周り

を確認する。

同じメーカーのアメリカンでも、
車種が違えばシーシーバーの取り付け条件が異なる場合がある。


# 35. シーシーバーと他のカスタム

シーシーバーは単独で考えるより、
他のカスタムと組み合わせて考える。

代表例：

---

### シーシーバー
+
### サイドバッグ

スタイルと積載性を両立しやすい。

### シーシーバー

# 36. よくある勘違い

## 「シーシーバー＝背もたれ」

必ずしもそうではない。

スタイル目的、
荷物固定目的、
フェンダー支持目的などでも使用される。


## 「シーシーバー＝チョッパー専用」

違う。

クルーザー、
アメリカン、
ボバー、
ツーリング系などでも使用される。


## 「高ければ高いほどチョッパーらしい」

必ずしも正しくない。

車体全体とのバランスが重要。


## 「SR400用ならどのSR400にも付く」

必ずしもそうではない。

年式やリア周りのカスタム状態によって適合条件が変わる。


## 「シーシーバーが付けばタンデムできる」

違う。

タンデムに必要な条件は、
シート・ステップ・車体仕様なども含めて確認する。


## 「ボルトオンなら何も確認しなくていい」

違う。

取り付け状態、
クリアランス、
ボルト・ナット、
周辺部品との干渉などを確認する必要がある。


# 37. 取り付け時の基本確認

シーシーバーを取り付けた後は、

- ボルトが正しく締結されている
- 左右の固定状態が均等
- シーシーバーが傾いていない
- タイヤと干渉していない
- フェンダーと干渉していない
- シートと干渉していない
- サスペンション作動時に干渉しない
- ウインカーと干渉しない
- テールランプと干渉しない
- ナンバープレートと干渉しない
- 配線が挟まっていない
- 荷物固定用ベルトが可動部に接触しない

ことを確認する。


# 38. BIKER AIの回答方針

ユーザーがシーシーバーについて質問した場合、
まず質問の目的を判断する。

### 目的A：見た目

例：

「チョッパーっぽいシーシーバーが欲しい」

→ 高さ・形状・車体全体とのバランスを説明する。


### 目的B：取り付け

例：

「SR400にシーシーバーを付けたい」

→ 車種・年式・現在のリア周りを確認する。

必要に応じてCompatibility Knowledgeを参照する。


### 目的C：荷物

例：

「シーシーバーにバッグを付けたい」

→ 荷物固定方法と干渉について説明する。


### 目的D：タンデム

例：

「シーシーバー付けたら二人乗りできる？」

→ シーシーバーだけでは判断せず、
シート・ステップ・車体仕様などを確認する。


### 目的E：ワンオフ

例：

「シーシーバーを自作したい」

→ 材料・寸法・曲げ・溶接・固定方法などを考慮する。

強度に関係する加工については、
安全性を優先する。

# 40. Knowledge連携

シーシーバーについて回答する際、
必要に応じて以下のKnowledgeを組み合わせる。

## compatibility

パーツが車体に適合するか確認する場合。

## electrical

ウインカー・テールランプ・配線などを移設する場合。

## lighting

灯火類の位置変更を伴う場合。

## suspension

リアサスペンションや車高変更によるクリアランスを確認する場合。

## fuel

タンク変更など、リア周り以外のカスタムと組み合わせる場合。

## handlebars

チョッパー全体のスタイルバランスを考える場合。

## wheels_tires

タイヤサイズ変更によるクリアランスを確認する場合。

## brakes

リア周りの構造変更にブレーキ関連の変更が含まれる場合。

## safety

取り付け・荷物固定・タンデムなど、安全性が関係する場合。

## tools

取り付け作業に必要な工具を案内する場合。

## regulations

灯火類・ナンバープレート・車体寸法・タンデムなど、
法規が関係する場合。


# 41. 回答の基本原則

シーシーバーについて回答するときは、

「見た目」
「機能」
「適合」
「取り付け」
「安全性」

を分けて考える。

特に具体的な車種への取り付けについては、
車種・年式・現在のカスタム状態が分からない状態で、
適合を断定しない。

また、
製品によって仕様が異なるため、
具体的な寸法・強度・耐荷重・タンデム対応などは、
メーカーの製品情報や車両情報を確認して判断する。


# 42. BIKER AIの回答例

ユーザー：

「SR400をチョッパーにしたいんだけど、シーシーバーって付けた方がいい？」

回答方針：

シーシーバーは必須ではない。

ただし、
SR400をチョッパーらしいシルエットにしたい場合、
シーシーバーはリア側に強い縦のラインを作れるため、
ロングフォークや高めのハンドルなどと組み合わせると
チョッパーらしい雰囲気を出しやすい。

そのうえで、

- どのくらいの高さにするか
- ソロシートにするか
- リアフェンダーをどうするか
- バッグを付けるか
- タンデムするか

を決めてから選ぶ。

SR400の年式と現在のリア周りが分かれば、
取り付け方法まで絞り込める。


# 43. まとめ

シーシーバーは、

「背もたれ」

から始まり、

「荷物固定」
「フェンダー支持」
「カスタムパーツ」
「スタイルを表現するパーツ」

へと役割を広げてきた。

現在では、
実用性とデザイン性の両方を持つカスタムパーツとして使用されている。

特にチョッパーでは、
高さ・角度・形状によって車体のシルエットを大きく変えられる。

ただし、
シーシーバー単体ではなく、

- フロントフォーク
- ハンドル
- タンク
- シート
- リアフェンダー
- タイヤ
- サスペンション
- 灯火類

とのバランスを考えて選ぶことが重要。

シーシーバーは、
「付けるか付けないか」だけではなく、

「何のために付けるのか」
「どんなスタイルにしたいのか」
「車体にどう組み込むのか」

まで考えて選択するパーツである。
