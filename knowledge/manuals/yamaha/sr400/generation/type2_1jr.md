# 5. 1985年1JRの大きな変更

1985年モデルは、
Type 1からType 2へ移行する重要なモデル。

主な変更：

- フロントブレーキをディスクからドラムへ変更
- フロントホイールを19インチから18インチへ変更
- フォークブーツを採用
- バックステップ化
- ハンドルを低めのコンチネンタルタイプへ変更
- ガソリンタンクを14Lへ拡大
- エンジン内部の耐久性向上
- カム表面処理
- ロッカーアームの焼結チップ採用
- メタルガスケット採用
- カムチェーンアジャスターカバーをアルミ化

これらにより、
Type 1よりもクラシカルな外観を強めつつ、
ライディングポジションはスポーティになった。

ヤマハ自身も1985年モデルについて、
フロントブレーキのドラム化、
フォークブーツ装着、
ハンドル幅縮小・バックステップ化などを説明している。
