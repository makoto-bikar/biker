# YAMAHA SR400 Type 3 Knowledge

## 1. Knowledgeの目的

このKnowledgeは、
YAMAHA SR400 Type 3世代について、

- 車両識別
- 年式識別
- 型式識別
- 機種コード識別
- エンジン仕様
- キャブレター仕様
- ブレーキ仕様
- 電装仕様
- 排出ガス対策
- 年式による変更点
- カスタム適合判断の基礎情報

を提供するために使用する。

Type 3は、
2001年に登場したRH01J型を中心とする世代。

Type 2の1JR/3HT系とは
車両型式・ブレーキ・キャブレター・排出ガス対策・電装仕様などが異なる。

Type 3内部でも年式による変更が存在するため、

「Type 3だからすべて同じ仕様」

とは判断してはいけない。

# 3. Type 3の最大の特徴

Type 3は、
2001年のモデルチェンジによって
Type 2から大きく仕様変更された世代。

特に重要なのは以下。

- フロントディスクブレーキ復活
- BSR33キャブレター採用
- エア・インダクション・システム採用
- 排出ガス規制対応
- 前後サスペンションセッティング変更
- バッテリーチャージ方式変更
- 12L燃料タンク継続
- 18インチ前後ホイール継続
- キック始動継続

Type 2では
フロントブレーキがドラムだったが、

Type 3では
フロントが油圧式シングルディスクとなる。

これはType 2とType 3を識別するうえで
非常に重要な特徴。

# 5. 2001年モデルの重要変更

2001年モデルでは、
Type 2から大きな変更が行われた。

主な変更：

1.
フロントブレーキを
ドラムからディスクへ変更。

2.
BSRキャブレターを採用。

3.
エア・インダクション・システムを採用。

4.
排出ガス規制へ対応。

5.
前後サスペンションのセッティングを変更。

6.
バッテリーチャージ方式を変更。

Type 2以前の車両と
ブレーキ・キャブ・排出ガス対策・電装を
同一仕様として扱ってはいけない。

# 10. エア・インダクション・システム

Type 3では、
排出ガス規制対応のため
エア・インダクション・システムが採用された。

このシステムは、
排出ガスの浄化を目的としたもの。

したがって、

- エア・インダクション関連部品
- キャブレター
- マフラー
- エアクリーナー
- 吸気系

を変更する場合は、
単純な見た目や取付可否だけでは判断しない。

排出ガス・車検・法規への影響を
別Knowledgeで確認する。

- 電装

を確認する。

キャブレターを変更した場合、
燃調・始動性・走行性・排出ガスなどに
影響する可能性がある。

特に2003年以降は

- メーター
- CDI
- イグニッション
- ハーネス
- ECU関連
- TPS
- イモビライザー
- スイッチ
- バッテリー

などの交換では、
年式・機種コードを確認する。

# 38. イモビライザー

2003年モデルから
盗難抑止機能として
イモビライザーが標準装備された。

したがって、

2001〜2002年

と

2003年以降

では、
電装部品交換時の注意点が異なる。

キー・イグニッション・電装系を変更する場合は、
イモビライザーの有無を確認する。
