# YAMAHA SR400 Type 4 Knowledge

## 1. Knowledgeの目的

このKnowledgeは、
YAMAHA SR400 Type 4世代について、

- 車両識別
- 年式識別
- 型式識別
- 原動機型式識別
- FI仕様の識別
- エンジン仕様
- 燃料供給方式
- 電装仕様
- 排出ガス対策
- ブレーキ仕様
- 車体仕様
- 年式による変更
- Anniversary Edition
- Final Edition
- カスタム適合判断の基礎情報

を提供する。

Type 4は、
キャブレター仕様のType 3から大きく進化し、
フューエルインジェクション（FI）を採用した世代である。

Type 4では、
基本的にRH03J系を中心として扱う。

ただし、
2010年代後半には排出ガス規制対応などによる変更が存在するため、

「Type 4だからすべて同じ」

とは判断してはいけない。

必ず、

- 年式
- 認定型式
- 原動機型式
- 車体番号
- 現在の仕様
- 変更されている部品

を必要に応じて確認する。

# 5. 2010年FI化

2010年モデルでは、
従来のキャブレター式から
フューエルインジェクションへ変更された。

FI：

電子制御式燃料噴射装置

スロットルボディに
12孔インジェクターを配置。

燃料ポンプは
サイドカバー内側のサブタンクに配置された。

メインタンクは
従来からのティアドロップ形状を維持。

---

# 6. 2010年点火方式

FI化に合わせて、
点火方式も変更された。

Type 3：

C.D.I.

Type 4：

T.C.I.

2010年モデルでは、
フルトランジスター方式による
点火制御を採用。

そのため、

CDI
イグニッションコイル
ハーネス
ECU関連

などを、
Type 3とType 4で同一仕様として扱ってはいけない。

---

# 7. 2010年排気系

2010年モデルでは、
新設計マフラーと
三元触媒を採用。

さらに、
エキゾーストパイプに
O₂センサーを装備。

O₂センサーの情報を
FI制御へフィードバックし、
空燃比を補正する。

そのため、
Type 4の排気系は
単純な「マフラー＋エンジン」の構成ではない。

---

# 8. 三元触媒

2010年モデルのマフラーには、
貴金属を使用した
ハニカム触媒が配置されている。

目的：

排出ガス中の有害成分を低減する。

そのため、

- マフラー交換
- エキゾースト交換
- O₂センサー移設
- 触媒変更
- FI変更

などを行う場合は、

- 排出ガス
- O₂フィードバック
- 燃調
- 車検
- 法規

への影響を考慮する。

- エアクリーナー

単純に、

「マフラーを交換すれば終わり」

と判断してはいけない。

吸気・排気・燃料制御が
相互に影響する可能性がある。

# 14. マフラー交換

Type 4では、
マフラーに排出ガス対策部品が組み込まれている。

そのため、
マフラー交換では、

- 年式
- 型式
- 排気系構造
- 触媒
- O₂センサー
- 排気音
- 排出ガス
- 車検
- 法規

を確認する。

特に、
触媒やO₂センサーを無効化するような変更は、
安全・環境・法規面の確認が必要。

年式・型式を確認する。

- スロットルボディ

などを確認する。

FI車では、
キャブレター車と同じ感覚で
燃料コックやホースを扱わない。

# 46. ハンドル交換

Type 4のハンドル交換では、

- ハンドル径
- 幅
- 高さ
- プルバック
- ブレーキホース
- クラッチケーブル
- スロットル
- スイッチ配線
- タンク干渉
- メーター
- ハンドルロック
- 操舵範囲

を確認する。

特に、
フロントブレーキが油圧式のため、
ハンドル高さを大きく変更する場合は
ブレーキホースの長さ・取り回しを確認する。

# 47. マフラー交換

Type 4のマフラー交換では、

1. 年式
2. 認定型式
3. 排出ガス規制
4. 触媒
5. O₂センサー
6. 取付位置
7. 排気音
8. 排出ガス
9. 車検

を確認する。

特に2018年以降は、
2BL-RH03Jの排出ガス規制対応仕様を
考慮する。

# 48. エアクリーナー交換

FI車では、
吸気系を変更すると
燃料制御やエンジン特性に
影響する可能性がある。

したがって、

「吸気量を増やせば必ずパワーアップする」

などと断定してはいけない。

必要に応じて、

- FI制御
- 燃調
- O₂フィードバック
- 排出ガス

を確認する。

# 49. ブレーキカスタム

Type 4のフロントブレーキは
油圧式シングルディスク。

ブレーキ関連部品は
重要保安部品。

適合が不明な場合は、

- 部品メーカー適合表
- 純正部品番号
- サービスマニュアル
- 専門店

などで確認する。

- O₂センサー
- インジェクター
- TCI
- バッテリー
- ハーネス

などに関係する場合、
安易に配線を変更してはいけない。

# 57. Type 4とType 5の境界

このKnowledgeでは、

2010〜2021年

Type 4の最終モデルとして扱う。

Type 4以降の国内量産型SR400を
別世代として設定しない。
