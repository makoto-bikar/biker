# Safety: Test Ride

## Purpose

このKnowledgeは、整備・修理・カスタム後の二輪車を走行確認するときの安全確保を目的とする。

対象:

- 整備後の初回走行
- カスタム後の初回走行
- ブレーキ作業後
- サスペンション作業後
- ホイール・タイヤ交換後
- ハンドル交換後
- 電装作業後
- 燃料系作業後
- エンジン作業後
- 排気系作業後
- フレーム・車体変更後
- 長期間保管後の再始動・走行
- 異常発生後の確認走行

このKnowledgeは、車種固有の整備仕様を定義するものではない。

車種固有の情報が必要な場合は、

- vehicle_registry.json
- manuals/
- generation Knowledge
- systems/
- custom/
- regulations/

を優先する。

---

# 1. Core Safety Principle

整備・カスタム後の初回走行では、

「走れるか」

ではなく、

「安全に走行・停止・操縦できるか」

を確認する。

基本原則:

1. 走行前点検を行う
2. 異常がある状態で走行しない
3. 最初から高速走行しない
4. 最初から強いブレーキを行わない
5. 安全な環境で確認する
6. 少しずつ確認範囲を広げる
7. 異常を感じたら直ちに停止する
8. 原因不明の異常を無視しない

---

# 2. Never Guess Rule

以下の情報が不明な場合、AIは安全性を推測して確定的に回答してはいけない。

- 車種
- 年式
- 型式
- 作業内容
- 変更部品
- 部品メーカー
- 部品型番
- ブレーキ仕様
- サスペンション仕様
- ホイール・タイヤ仕様
- 電装仕様
- 燃料系仕様
- フレーム変更内容
- メーカー指定値
- 部品メーカー指定値
- 法規適合状況

「たぶん大丈夫」
「普通は走れる」
などの推測だけで走行を推奨しない。

---

# 3. When Not to Test Ride

以下の状態では確認走行を行わない。

- ブレーキに異常がある
- 燃料漏れがある
- 電装系に重大な異常がある
- タイヤに異常がある
- ホイール取り付けに不安がある
- ハンドル操作に異常がある
- サスペンションに重大な異常がある
- 車体に重大な損傷がある
- 部品の固定状態に不安がある
- 原因不明の重大な異常がある

---

# 4. Pre-Ride Inspection

走行前に車両全体を確認する。

## Basic checklist

- [ ] タイヤに異常がない
- [ ] ホイールに異常がない
- [ ] ブレーキが正常
- [ ] ブレーキフルード漏れがない
- [ ] ブレーキランプが正常
- [ ] ハンドルが正常
- [ ] スロットルが正常
- [ ] クラッチが正常
- [ ] シフト操作が正常
- [ ] サスペンションが正常
- [ ] 燃料漏れがない
- [ ] 燃料臭に異常がない
- [ ] 電装系が正常
- [ ] ヘッドライトが正常
- [ ] ウインカーが正常
- [ ] ホーンが正常
- [ ] エンジンに異常がない
- [ ] オイル漏れがない
- [ ] 冷却系に異常がない
- [ ] 排気系に異常がない
- [ ] 主要部品が確実に固定されている
- [ ] 工具・ウエスなどを車体周辺に置き忘れていない

- マスターシリンダー交換
- ホース交換
- ブレーキ調整

### Suspension

- フォーク交換
- フォーク高さ変更
- ローダウン
- ロングフォーク
- リアショック交換

### Wheel / Tire

- タイヤ交換
- ホイール交換
- スポーク変更
- ワイドタイヤ

### Electrical

- LED化
- ウインカー変更
- メーター変更
- USB電源追加
- バッテリー移設

### Fuel

- タンク交換
- 燃料ホース交換
- フューエルコック交換

### Chassis

- ステップ変更

作業内容によって確認項目を変える。

# 6. Static Check

走行前に、停車状態で確認できるものを確認する。

確認項目:

- エンジン始動
- アイドリング
- スロットル
- クラッチ
- シフト
- ブレーキ
- ライト
- ウインカー
- ホーン
- メーター
- 燃料漏れ
- オイル漏れ
- 異常音
- 異常振動

停車状態で重大な異常がある場合、走行しない。

---

# 7. Brake Check

ブレーキ作業後は、走行前にブレーキの状態を確認する。

確認項目:

- レバー・ペダル操作
- ブレーキの反応
- 異常な柔らかさ
- 異常な深さ
- フルード漏れ
- パッド
- ローター
- キャリパー

異常がある場合は走行しない。

- タイヤ
- フェンダー

- フェンダー
- チェーン・ベルト

タイヤと車体・サスペンション・ブレーキなどの干渉がないことを確認する。

# 10. Handlebar Check

ハンドル変更後は、

- 左右の操舵
- スロットル
- ブレーキレバー
- クラッチレバー
- ミラー
- ブレーキホース
- クラッチケーブル
- スロットルケーブル
- 電装配線

を確認する。

ハンドルを左右いっぱいまで切った状態でも、

- ケーブルが引っ張られない
- ホースが引っ張られない
- 配線が挟まらない
- タンクと干渉しない

ことを確認する。

# 13. Engine Check

エンジン作業後は、

- 始動
- アイドリング
- スロットル反応

- オイル漏れ

# 15. Test Environment

初回走行は、安全に確認できる環境を選択する。

可能な限り、

- 交通量が少ない
- 見通しが良い
- 路面状態が良い
- 十分なスペースがある
- 危険な障害物が少ない

場所を選ぶ。

公道での確認が必要な場合は、道路交通法その他の法令を守る。

---

# 16. Weather and Road Conditions

以下の状況では初回走行を避けることを検討する。

- 強い雨
- 路面が滑りやすい
- 強風
- 視界不良
- 凍結
- 大量の砂・砂利
- その他、車両挙動を確認しにくい状況

初回走行では、車両以外のリスクも減らす。

---

# 17. Initial Movement

最初は低い速度・短い距離から確認する。

最初から、

- 高速走行
- 急加速
- 急ブレーキ
- 急旋回
- 高負荷走行

を行わない。

まず、

- 直進
- 軽いブレーキ
- 軽い操舵
- スロットル操作
- シフト操作

など、基本的な挙動を確認する。

---

# 18. Brake Test

ブレーキ確認では、周囲の安全を確保したうえで慎重に確認する。

確認項目:

- ブレーキが反応する
- 左右に異常に流れない
- 異常音がない
- 異常振動がない
- レバー・ペダルに異常がない
- ブレーキ解除後に引きずりがない

異常がある場合は走行を中止する。

---

# 19. Steering Test

操舵確認では、

- ハンドルが左右に正常に動く
- 引っ掛かりがない
- 異常なガタがない
- ケーブル・ホースが干渉しない
- 車体が異常に流れない

ことを確認する。

ハンドル変更やフォーク変更後は特に注意する。

---

# 20. Suspension Test

走行時に、

- 異常な跳ね
- 異常な沈み込み
- 異常音
- 異常振動
- 操縦安定性の変化
- タイヤ・フェンダー等の干渉

がないか確認する。

異常を感じた場合は停止する。

---

# 21. Acceleration Test

加速確認では、最初から大きな負荷をかけない。

確認項目:

- スロットル反応
- エンジン回転
- クラッチ
- シフト
- 異常音
- 異常振動

燃料系・吸気系・排気系を変更した車両では、エンジン挙動を慎重に確認する。

---

# 22. Electrical Test During Ride

走行中に、

- メーター
- 警告灯
- ヘッドライト
- ウインカー
- ブレーキランプ

などが正常に作動するか確認する。

走行中に電装系の異常が発生した場合は、安全な場所に停止する。

---

# 23. Noise and Vibration

整備・カスタム後に、

- 新しい異音
- 新しい振動
- 金属音
- 異常な共振
- 部品のガタつき

が発生した場合は原因を確認する。

「カスタムしたから普通」と決めつけない。

---

# 24. Stop Immediately Conditions

以下の状態では、可能な限り安全な場所に停止する。

- ブレーキ異常
- ハンドル操作異常
- タイヤ異常
- 強い振動
- 強い異音
- 燃料臭
- 燃料漏れ
- オイル漏れ
- 電装異常
- エンジン異常
- 異常な発熱
- 車体の挙動が明らかにおかしい

---

# 25. Post-Ride Inspection

初回走行後は再度車両を確認する。

確認項目:

- 燃料漏れ
- オイル漏れ
- フォークオイル漏れ
- ブレーキフルード漏れ
- ボルト・固定部
- ホイール
- タイヤ
- ブレーキ
- サスペンション
- 排気系
- 電装配線
- 異常な発熱
- 異常音
- 異常振動

走行前に問題がなくても、走行後に再確認する。

---

# 26. Re-Torque / Fastener Check

走行後に再確認が必要な部品については、車両メーカー・部品メーカーの指定方法を優先する。

締付トルクは推測しない。

特に重要な部品では、

- アクスル
- ブレーキ
- ハンドル
- フォーク
- サスペンション
- ホイール
- ステップ
- フレーム関連部品

などを確認する。

---

# 27. Break-In / Bedding

新品または交換した部品には、メーカーが慣らし・初期処理・ベディング等を指定している場合がある。

その場合はメーカー指定方法を優先する。

特に、

- ブレーキパッド
- ブレーキローター
- タイヤ
- サスペンション
- エンジン関連部品

などでは、部品メーカー・車両メーカーの指示を確認する。

具体的な手順を推測しない。

---

# 28. Long-Term Monitoring

カスタム後は初回走行だけで安全性が完全に確認できるとは限らない。

その後も、

- ボルトの緩み
- オイル漏れ
- 燃料漏れ
- 配線の擦れ
- ホースの損傷
- タイヤ摩耗
- ブレーキ摩耗
- 異音
- 異常振動

などを確認する。

---

- ワイドタイヤ

- タンク変更

などを組み合わせた場合は、個別の変更だけではなく全体のバランスを確認する。

# 30. Legal Safety

確認走行を行う場合でも、車両が法規・保安基準に適合していることとは別問題である。

「安全に走れる」
と
「公道を走行できる」
は同じではない。

カスタム内容によって、

- 保安基準
- 車検
- 構造変更
- 灯火類
- ミラー
- タイヤ・ホイール
- 排気・騒音

などを確認する。

2. 作業・カスタム内容を確認
3. 重要部品への変更を確認
4. ブレーキを確認
5. タイヤ・ホイールを確認
6. サスペンションを確認
7. ハンドル・操舵系を確認
8. 電装を確認
9. 燃料系を確認
10. エンジン・排気系を確認
11. 法規を確認
12. 初回走行条件を確認
13. safety/test_ride.mdを確認

---

# 32. Answer Classification

### Confirmed

公式資料・メーカー資料・整備資料などで確認できる内容。

### Likely

一般的には可能性が高いが、車両・部品・作業内容によって変わる内容。

### Unknown

必要な情報が不足しており判断できない内容。

### Must Verify

安全上、メーカー資料・整備マニュアル・部品メーカー資料などで確認が必要な内容。

---

# 33. Important Distinctions

AIは以下を混同しない。

### Starts

エンジンが始動するか。

### Moves

車両が動くか。

### Works

各部品が正常に機能するか。

### Safe to Ride

安全に走行できる状態か。

### Legal to Ride

公道走行に必要な法規・保安基準等を満たしているか。

エンジンがかかり、車両が動いたからといって、
安全・合法とは限らない。

# 36. Uncertainty Policy

確認走行は、整備・カスタム後の車両を実際に動かす工程であるため、不確かな情報を安全情報として断定しない。

特に、

- 走行可能性
- ブレーキ性能
- タイヤ適合
- サスペンション設定
- ハンドル操作
- フレーム変更
- 電装状態
- 燃料漏れ
- 部品固定
- 法規適合

については推測しない。

情報が不足している場合は、ユーザーに追加情報を確認する。

---

# 37. Core Principle

確認走行に関するAI回答では、

「エンジンがかかったか」

だけではなく、

「止まれるか」
「曲がれるか」
「正常に操作できるか」
「異常がないか」
「部品が外れないか」
「干渉しないか」
「燃料・オイル等が漏れないか」
「電装が正常か」
「法規上問題がないか」

まで考える。

最初の走行は、
性能を試すためではなく、
安全に正常動作することを確認するために行う。

異常を感じたら、
「もう少し乗って様子を見る」ではなく、
安全な場所に停止して原因を確認する。
