# Chassis System

## Purpose

このKnowledgeは、オートバイの車体・シャシーに関する
共通・汎用的な知識を定義する。

対象：

- フレーム
- スイングアーム
- ステアリング
- ステアリングステム
- フロントホイール
- リアホイール
- タイヤ
- アクスル
- ホイールベアリング
- ステアリングベアリング
- 車体アライメント
- ホイールアライメント
- 車体剛性
- 車高
- 車体カスタム
- シャシートラブル診断

このファイルは車種共通の基本知識を扱う。

車種・年式・型式ごとの具体的なフレーム構造、
ホイールサイズ、タイヤサイズ、アクスル寸法、
ベアリング仕様、締付トルクなどは
manuals/ 以下の車種・世代別Knowledgeを優先する。


# 1. Chassis System Overview

シャシーは、
エンジンやサスペンション、ホイールなどを支え、
走行時の安定性や操縦性を決める車体構造。

主な構成：

- フレーム
- ステアリング
- フロントフォーク
- スイングアーム
- ホイール
- タイヤ
- アクスル
- ベアリング
- サスペンション

シャシーは単独で考えるのではなく、

- サスペンション
- タイヤ
- ブレーキ
- 駆動系
- 車体重量
- 車体ジオメトリー

とのバランスで考える。


# 2. Frame

フレームは、
エンジンやサスペンションなどを支える
車体の主要構造。

主な役割：

- 車体各部を支える
- エンジンを保持する
- サスペンションを保持する
- ライダーの荷重を支える
- 走行中に発生する荷重を受ける

フレーム形式は車種によって異なる。

代表例：

- ダブルクレードル
- シングルクレードル
- ダイヤモンド
- ツインスパー
- バックボーン
- トラス
- モノコック

など。

フレーム形式だけで車両性能を判断しない。


# 3. Frame Modification

フレームは車体の重要構造部品。

代表的なカスタム：

- フレーム加工
- シートレール加工
- サブフレーム変更
- フレーム補強
- タブ追加
- マウント変更

フレーム加工では、

- 強度
- 剛性
- 溶接
- 応力集中
- 荷重経路
- 部品干渉
- 防錆
- 法規

などを考慮する。

特にフレームの切断・溶接・形状変更は、
単純な外観変更として扱わない。


# 4. Frame Inspection

フレームを点検する場合は、

- 曲がり
- クラック
- 溶接部
- 腐食
- 変形
- ボルト・マウント部
- エンジンマウント
- サスペンション取付部

などを確認する。

転倒や事故歴がある車両では、
外観だけでなく車体全体のアライメントを確認する。


# 5. Swingarm

スイングアームは、
リアホイールを車体へ支持する部品。

主な役割：

- リアホイールを支持する
- リアサスペンションの動きを受ける
- 駆動力・制動力を車体へ伝える
- リアホイールの位置を保持する

代表的な構成：

- スイングアーム本体
- ピボット
- アクスル
- ベアリング / ブッシュ
- リアサスペンション取付部

車種によって構造は異なる。


# 6. Swingarm Inspection

確認項目：

- 曲がり
- クラック
- 腐食
- ピボット部
- ベアリング
- ブッシュ
- アクスル周辺
- サスペンション取付部

スイングアームに異常がある場合、
車体の安定性やホイールアライメントに影響する可能性がある。


# 7. Steering System

ステアリングシステムは、
フロントホイールの向きを操作する機構。

主な構成：

- ハンドル
- トップブリッジ
- ステアリングステム
- ステアリングベアリング
- フロントフォーク

ハンドル操作は、
タイヤを通じて車両の進行方向を変える。

ステアリング系は安全性に直結する重要部品。


# 8. Steering Stem

ステアリングステムは、
フロントフォークとフレームを接続し、
ステアリング操作を可能にする。

確認項目：

- ステムナット
- ベアリング
- ベアリングレース
- ガタ
- 動作
- 締付状態

ステアリングに異常なガタや引っ掛かりがある場合は、
走行前に原因を確認する。


# 9. Steering Bearing

ステアリングベアリングは、
ステアリングステムを滑らかに回転させる。

異常がある場合、

- ハンドルが重い
- ハンドルが引っ掛かる
- 中立付近で違和感がある
- ガタがある
- 操縦性が不安定

などの症状が発生する可能性がある。

ベアリング交換時は、
車種指定の調整方法を優先する。


# 10. Steering Diagnosis

## 症状：ハンドルが重い

確認項目：

- ステアリングベアリング
- フロントフォーク
- フォークの取付状態
- タイヤ空気圧
- タイヤ状態
- ステム調整


## 症状：ハンドルにガタがある

確認項目：

- ステアリングベアリング
- ステムナット
- フォーク取付部
- ホイールベアリング
- アクスル


## 症状：ハンドルがまっすぐなのに車体が流れる

確認項目：

- ホイールアライメント
- タイヤ状態
- タイヤ空気圧
- フォーク取付状態
- ステアリング
- フレーム
- スイングアーム


# 11. Wheel

ホイールは、
タイヤを支持し車体と路面の間で
荷重や駆動・制動力を伝える。

代表的な構造：

- スポークホイール
- キャストホイール
- その他の特殊構造

ホイールには、

- 荷重
- 駆動力
- 制動力
- コーナリング時の力

が加わる。


# 12. Spoke Wheel

スポークホイールでは、
スポークによってハブとリムを接続する。

確認項目：

- スポークの緩み
- スポークの損傷
- リムの変形
- ニップル
- ハブ
- ベアリング

スポークホイールでは、
スポーク張力のバランスも重要。

調整方法や指定値は、
車種・ホイール仕様によって異なる。


# 13. Cast Wheel

キャストホイールは、
一体成形などによって作られたホイール。

確認項目：

- クラック
- 曲がり
- 変形
- 腐食
- ベアリング
- アクスル周辺

強い衝撃を受けた場合は、
外観だけで判断しない。


# 14. Wheel Bearing

ホイールベアリングは、
ホイールを滑らかに回転させる。

異常がある場合、

- ゴロゴロする
- 回転が重い
- ガタがある
- 異音がする
- ホイールが不安定

などの症状が発生する可能性がある。

ベアリングの異常を確認した場合は、
安全のため早めに点検・交換する。


# 15. Axle

アクスルは、
ホイールを車体へ固定・支持する軸。

フロント・リアそれぞれに存在する。

取付時には、

- アクスルの向き
- スペーサー
- ベアリング
- フォーク
- スイングアーム
- ブレーキ
- アライメント

などを確認する。

具体的な締付トルクは
車種別サービスマニュアルを優先する。


# 16. Tire

タイヤは、
車体と路面が直接接触する部品。

主な役割：

- 駆動力を伝える
- 制動力を伝える
- コーナリング力を発生させる
- 路面からの衝撃を吸収する

タイヤはシャシー性能に大きく影響する。


# 17. Tire Size

タイヤサイズを変更する場合は、

- 幅
- 扁平率
- リム径
- 荷重能力
- 速度記号
- リム適合
- フェンダーとのクリアランス
- チェーン / ベルトとのクリアランス
- ブレーキとの干渉

などを確認する。

「物理的に入る」
ことと
「適正に使用できる」
ことは同じではない。


# 18. Tire Pressure

タイヤ空気圧は、
操縦性・乗り心地・タイヤ寿命・安全性に影響する。

空気圧が低すぎる場合：

- 操縦性が変化する
- タイヤが過度に変形する
- 発熱が増える可能性がある
- 摩耗に影響する

空気圧が高すぎる場合：

- 接地感が変化する
- 乗り心地が悪化する場合がある
- タイヤの接地状態が変化する

基本的には車両メーカー指定値を優先する。


# 19. Tire Wear

タイヤ摩耗の確認項目：

- 溝
- 偏摩耗
- ひび割れ
- 異物
- 傷
- 側面の状態
- 製造時期
- 空気圧

偏摩耗がある場合は、
タイヤだけでなく

- アライメント
- サスペンション
- 空気圧
- ホイール

なども確認する。


# 20. Wheel Alignment

ホイールアライメントは、
前後ホイールが適切な位置関係にある状態を指す。

特にリアホイールでは、

- チェーンライン
- スイングアーム
- アクスル
- アジャスター

などとの関係を確認する。

アライメント不良では、

- タイヤ摩耗
- ハンドリング異常
- 駆動系摩耗
- 車体の流れ

などにつながる可能性がある。


# 21. Wheelbase

ホイールベースは、
前後ホイールの中心間距離。

ホイールベースが変化すると、
車体の安定性や旋回特性に影響する可能性がある。

以下の変更によって変化する場合がある：

- スイングアーム変更
- フォーク変更
- 車高変更
- ホイール変更

具体的な数値は車種別Knowledgeを優先する。


# 22. Rake and Trail

ステアリングジオメトリーには、

- キャスター
- トレール

などの要素がある。

これらは、

- ハンドリング
- 直進安定性
- 旋回性
- ステアリングの応答

などに関係する。

サスペンションやホイールサイズ、
車高などを変更すると、
これらのジオメトリーが変化する可能性がある。


# 23. Chassis Customization

代表的なシャシーカスタム：

- ホイール交換
- タイヤ変更
- スイングアーム交換
- フロントフォーク交換
- ステム交換
- ハンドル交換
- 車高変更
- フレーム加工
- フレーム補強
- ロングフォーク
- ワイドタイヤ

カスタムでは、
見た目だけではなく

- 強度
- クリアランス
- アライメント
- ジオメトリー
- 操縦性
- ブレーキ
- サスペンション
- 駆動系
- 法規

への影響を確認する。


# 24. Handlebar

ハンドル交換では、

- 幅
- 高さ
- プルバック
- グリップ位置
- ケーブル長
- ブレーキホース
- 配線
- スイッチ類
- タンクとの干渉
- フォークとの干渉

を確認する。

ハンドルを変更すると、
操作姿勢やケーブル類の取り回しも変化する。

ハンドルを左右いっぱいまで切った状態で、
ケーブルやホースが引っ張られないことを確認する。


# 25. Chassis Geometry

シャシーのジオメトリーは、
複数の部品の位置関係によって決まる。

関連する要素：

- キャスター
- トレール
- ホイールベース
- 車高
- フォーク長
- スイングアーム長
- ホイール径
- タイヤ外径

一つの部品を変更しても、
車体全体の挙動が変化する可能性がある。

そのため、
大型カスタムでは個別部品ではなく
車体全体を見る。


# 26. Chassis Diagnosis

## 症状：走行中に車体が左右に流れる

確認項目：

- タイヤ空気圧
- タイヤ摩耗
- ホイールアライメント
- ステアリング
- フォーク
- スイングアーム
- フレーム


## 症状：走行中に振動する

確認項目：

- タイヤ
- ホイール
- ホイールバランス
- ベアリング
- アクスル
- フォーク
- 駆動系


## 症状：ホイールから異音がする

確認項目：

- ホイールベアリング
- ブレーキ
- タイヤ
- アクスル
- スペーサー


## 症状：タイヤが偏摩耗する

確認項目：

- 空気圧
- アライメント
- サスペンション
- ホイール
- タイヤ状態


# 27. Chassis and Suspension

シャシーとサスペンションは
独立したシステムではない。

例えば、

- 車高変更
- フォーク交換
- リアショック交換
- ロングフォーク

などによって、

- ジオメトリー
- ホイール位置
- 操縦性
- 最低地上高
- バンク角

などが変化する可能性がある。

そのため、
サスペンション変更時は
chassisとsuspensionの両方を確認する。


# 28. Chassis and Brakes

ホイールやフォークを変更する場合、
ブレーキとの適合を確認する。

確認項目：

- ブレーキディスク
- キャリパー
- キャリパーマウント
- ブレーキホース
- ホイール
- アクスル
- スペーサー

ホイール交換によって、
ブレーキ部品との位置関係が変わる場合がある。


# 29. Chassis and Drivetrain

リアホイールやスイングアームを変更する場合、
駆動系との関係を確認する。

確認項目：

- チェーンライン
- スプロケット
- ベルト
- プーリー
- スイングアーム
- タイヤ
- フレーム

特にワイドタイヤ化では、
チェーン・ベルト・フレームなどとの
クリアランスに注意する。


# 30. Safety

シャシーは走行安定性に直接関係する重要部品。

特に以下の作業は慎重に行う：

- フレーム加工
- スイングアーム交換
- ステアリングステム交換
- フォーク交換
- ホイール交換
- タイヤ交換
- アクスル脱着
- ベアリング交換
- 車高変更

作業後は、

- ボルト・ナットの固定
- アクスル
- ホイール
- ブレーキ
- ステアリング
- サスペンション
- タイヤ
- ケーブル・ホース
- 周辺部品との干渉

を確認する。

フレーム加工や重要構造部品の改造など、
強度判断が必要な作業は
専門店・専門業者への相談を推奨する。


# 31. Legal and Inspection Considerations

シャシーのカスタムでは、

- 車体寸法
- 車高
- タイヤ
- ホイール
- フレーム
- ハンドル
- 構造変更
- 安全装置

などが法規や車検に関係する場合がある。

具体的な法規については、
regulations/ 以下のKnowledgeを優先する。

法規が不明な場合、
「合法」と断定しない。

2. 車種・型式別のKnowledge

4. systems/suspension.md

6. systems/drivetrain.md

車種固有の仕様と一般論が異なる場合、
車種固有の資料を優先する。


# 33. Uncertainty Rules

以下の情報が不足している場合、
具体的な適合や作業方法を断定しない。

不足情報の例：

- メーカー
- 車種
- 年式
- 型式
- 世代
- 純正 / 社外
- 現在のカスタム状態

特に以下は確認する：

- ホイールサイズ
- タイヤサイズ
- アクスル径
- ベアリング
- スペーサー
- オフセット
- 取付寸法
- クリアランス
- 締付トルク
- 部品適合

不明な場合は、

- 確認が必要
- 車種・型式が必要
- メーカー資料の確認が必要
- 現物確認が必要
- 専門店への確認を推奨

などと明示する。


# 34. Important Principle

シャシーカスタムでは、

「付くかどうか」

だけではなく、

- 強度
- アライメント
- クリアランス
- ジオメトリー
- 操縦性
- 制動性能
- サスペンション性能
- 駆動系
- 安全性
- 法規

まで確認する。

特にフレーム・ステアリング・ホイール・タイヤは
走行安全性に直接関係するため、
見た目だけを基準に判断しない。
