# Electrical System

## Purpose

このKnowledgeは、オートバイの電装システムに関する
共通・汎用的な知識を定義する。

対象：

- バッテリー
- 発電・充電システム
- ヒューズ
- リレー
- 配線
- スイッチ
- アース
- ヘッドライト
- テールランプ
- ブレーキランプ
- ウインカー
- メーター
- ホーン
- セルモーター
- イグニッション
- ECU / CDI / TCI
- LED化
- 電装カスタム
- 電装トラブル診断

このファイルは車種共通の基本知識を扱う。

車種・年式・型式ごとの具体的な配線、
コネクター形状、ヒューズ容量、電圧、
点火方式、純正回路などは
manuals/ 以下の車種・世代別Knowledgeを優先する。


# 1. Electrical System Overview

オートバイの電装システムは、

- 電力を作る
- 電力を蓄える
- 電力を配る
- 電装部品を制御する

という役割を持つ。

代表的な構成：

- バッテリー
- 発電機
- レギュレーター / レクチファイア
- ヒューズ
- メインハーネス
- スイッチ
- リレー
- アース
- ランプ類
- 点火装置
- ECU / CDI / TCI
- セルモーター

車種によって構成や方式は異なる。


# 2. Battery

バッテリーは電気エネルギーを蓄える部品。

主な役割：

- エンジン始動時の電力供給
- 灯火類への電力供給
- 電装品への電力供給
- 電圧の安定化

バッテリーの状態が悪いと、

- セルが回らない
- セルの回転が弱い
- ライトが暗い
- ウインカーの動作が不安定
- メーターが正常に動作しない
- エンジン始動に影響する

などの症状が発生する場合がある。


# 3. Battery Inspection

バッテリーを確認する場合は、

- 外観
- 端子
- 端子の緩み
- 腐食
- 配線
- バッテリー電圧
- 充電状態

などを確認する。

電圧だけではバッテリーの状態を完全には判断できない。

始動時の電圧低下など、
負荷がかかった状態も診断材料になる。


# 4. Charging System

充電システムは、
エンジンが動いているときに電力を発生させ、
車両の電装系へ供給するとともに
バッテリーを充電する。

一般的な構成：

バッテリー
↓
車両電装

発電機
↓
レギュレーター / レクチファイア
↓
バッテリー

ただし車種によって構成は異なる。


# 5. Generator

発電機は、
エンジンの回転を利用して電力を発生させる。

代表的な構成：

- ステーター
- ローター / フライホイール

発電方式は車種によって異なる。

発電機に異常がある場合、

- バッテリーが充電されない
- 電装が不安定になる
- 走行中に電圧が低下する

などの症状が発生する可能性がある。


# 6. Regulator / Rectifier

レギュレーター / レクチファイアは、
発電された電力を車両の電装システムで
使用できる状態に整える役割を持つ。

役割には、

- 整流
- 電圧制御

などがある。

異常がある場合、

- 充電不足
- 過充電
- バッテリー異常
- 電装部品の故障

につながる可能性がある。

具体的な正常電圧値は、
車種・年式・発電方式によって異なるため、
車種別資料を優先する。


# 7. Fuse

ヒューズは、
異常な電流が流れた際に回路を保護する部品。

ヒューズが切れた場合は、
単純に交換するだけではなく
原因を確認する。

原因の例：

- 配線のショート
- 電装部品の故障
- 配線損傷
- 誤配線
- 過電流

ヒューズ交換時は、
必ず車種指定の容量を使用する。

容量を大きくして代用しない。


# 8. Relay

リレーは、
小さな制御電流で大きな電流を扱うためなどに使用される。

使用例：

- スターター
- ヘッドライト
- ホーン
- 燃料ポンプ
- 補助電装品

リレーに異常がある場合、

- 電装品が動作しない
- 動作が不安定
- スイッチを操作しても反応しない

などの症状が発生する場合がある。


# 9. Wiring Harness

メインハーネスは、
車両の各電装部品を接続する配線群。

一般的な考え方：

バッテリー
↓
メインヒューズ
↓
メインハーネス
↓
各スイッチ / リレー
↓
各電装部品
↓
アース

実際の回路構成は車種によって異なる。

配線作業では、

- 配線色
- コネクター
- 端子
- 極性
- 電源
- アース
- ヒューズ
- スイッチ

を確認する。


# 10. Ground

アースは、
電気回路を成立させる重要な経路。

アース不良では、

- ライトが暗い
- ウインカーが不安定
- ホーンが弱い
- 電装品が動かない
- 複数の電装品が同時に不安定

などの症状が発生する場合がある。

アース確認では、

- 端子の緩み
- 腐食
- 接触面
- 配線断線
- フレームとの接続

などを確認する。


# 11. Switches

スイッチは、
電気回路のON/OFFや切り替えを行う。

代表例：

- イグニッションスイッチ
- キルスイッチ
- ライトスイッチ
- ウインカースイッチ
- ブレーキスイッチ
- ホーンスイッチ
- スタータースイッチ

スイッチ不良の場合、

- 操作しても電装品が動かない
- 接触不良
- 動作が不安定

などが発生する可能性がある。


# 12. Headlight

ヘッドライトは、
前方を照らすための灯火装置。

代表的な方式：

- ハロゲン
- LED
- その他の車種指定方式

交換時には、

- 電圧
- 消費電力
- コネクター
- 極性
- サイズ
- 取付方法
- 発熱
- 光軸

を確認する。

LEDだから必ずそのまま交換できるとは限らない。


# 13. Tail Light

テールランプは、
後方から車両を認識できるようにする灯火。

ブレーキランプと一体になっている構造もある。

確認項目：

- 点灯
- ブレーキ操作時の変化
- 配線
- コネクター
- アース
- ランプ本体


# 14. Brake Light

ブレーキランプは、
ブレーキ操作を後方へ知らせる。

一般的に、

- フロントブレーキスイッチ
- リアブレーキスイッチ

などによって制御される。

ブレーキランプがつかない場合は、

1. バルブ / LED
2. ヒューズ
3. スイッチ
4. 配線
5. アース
6. 電源

などに分けて確認する。

具体的な診断手順は車種の配線図を優先する。


# 15. Turn Signals

ウインカーは、
車両の進行方向を周囲へ知らせる灯火装置。

構成例：

- ウインカーランプ
- ウインカーリレー
- スイッチ
- 配線
- アース

LED化する場合、
純正リレーとの組み合わせによっては
点滅速度が変化する場合がある。

そのため、

- LED対応リレー
- 抵抗
- 電子制御式リレー

などが必要になる場合がある。

車種ごとの適合を確認する。


# 16. Horn

ホーンは、
周囲へ警告するための電装部品。

動作しない場合：

- ヒューズ
- スイッチ
- リレー
- 配線
- アース
- ホーン本体

を確認する。


# 17. Starter Motor

セルモーターは、
エンジンを始動するためにクランクを回転させる。

一般的な始動回路では、

バッテリー
↓
スターター回路
↓
セルモーター
↓
エンジン

となる。

車種によっては、

- スターターリレー
- ニュートラルスイッチ
- クラッチスイッチ
- サイドスタンドスイッチ
- ECU / 制御装置

などが関係する。


# 18. Ignition System

点火システムは、
エンジン内部で混合気を燃焼させるための
点火を制御する。

代表的な構成：

- イグニッションコイル
- スパークプラグ
- CDI
- TCI
- ECU
- クランクポジションセンサー

など。

車種によって構成は大きく異なる。

そのため、
点火方式は車種・年式・型式を確認してから判断する。


# 19. CDI / TCI / ECU

点火・エンジン制御装置には
複数の方式が存在する。

代表例：

- CDI
- TCI
- ECU

これらは同じものではない。

システムによって、

- 点火タイミング
- 燃料制御
- センサー入力
- エンジン制御

などの役割が異なる。

車種別Knowledgeに具体的な情報がある場合は、
そちらを優先する。


# 20. Electrical Customization

代表的な電装カスタム：

- LEDウインカー
- LEDテールランプ
- ヘッドライト交換
- 小型ウインカー
- メーター交換
- ホーン交換
- USB電源
- スマートフォン電源
- グリップヒーター
- 補助灯
- 電装スイッチ追加

電装カスタムでは、

- 消費電力
- 電源容量
- ヒューズ
- 配線サイズ
- リレー
- アース
- 防水
- 発熱
- 取付位置

を確認する。


# 21. Adding Electrical Accessories

USB電源などの追加電装品を取り付ける場合、
単純に既存配線へ接続するだけではなく、
車両全体の電力負荷を考慮する。

確認項目：

- 電源の取り出し位置
- 常時電源 / ACC電源
- 消費電流
- ヒューズ
- リレー
- 配線
- アース
- 防水
- バッテリー容量
- 発電能力

特にエンジン停止中に使用する電装品は、
バッテリー消費に注意する。


# 22. LED Conversion

ハロゲンなどからLEDへ変更する場合は、

- 電圧
- 消費電力
- 極性
- コネクター
- 発熱
- 光軸
- リレー
- 抵抗
- 取付スペース

を確認する。

LED化によって消費電力が低下すると、
純正ウインカーリレーとの組み合わせによって
正常に点滅しなくなる場合がある。


# 23. Electrical Diagnosis

電装トラブルでは、
いきなり部品を交換しない。

基本的な考え方：

症状
↓
電源確認
↓
ヒューズ確認
↓
アース確認
↓
スイッチ確認
↓
配線確認
↓
リレー確認
↓
部品確認

ただし実際の診断順序は
車種・回路によって異なる。


# 24. Symptom Diagnosis

## 症状：セルが回らない

確認項目：

- バッテリー
- バッテリー端子
- ヒューズ
- スタータースイッチ
- スターターリレー
- セーフティスイッチ
- 配線
- セルモーター


## 症状：セルの回転が弱い

確認項目：

- バッテリー状態
- バッテリー端子
- アース
- スターター回路
- セルモーター
- 充電状態


## 症状：ヘッドライトがつかない

確認項目：

- バルブ / LED
- ヒューズ
- スイッチ
- リレー
- 電源
- アース
- 配線
- コネクター


## 症状：ウインカーがつかない

確認項目：

- バルブ / LED
- ヒューズ
- リレー
- スイッチ
- 配線
- アース


## 症状：ウインカーの点滅が速い

確認項目：

- LED化
- バルブ容量
- リレー
- 抵抗
- 接続状態


## 症状：ホーンが鳴らない

確認項目：

- ヒューズ
- スイッチ
- リレー
- 配線
- アース
- ホーン本体


## 症状：バッテリーがすぐ上がる

確認項目：

- バッテリー状態

- 発電機
- レギュレーター / レクチファイア
- 漏電
- 追加電装品
- 配線
- 長期間の放置


# 25. Multimeter

電装作業では、
テスター / マルチメーターが重要な診断工具になる。

代表的な測定：

- 電圧
- 導通
- 抵抗

ただし、
測定方法や測定レンジを誤ると
部品やテスターを破損する可能性がある。

電圧測定と電流測定は方法が異なる。

特に電流測定では、
テスターを回路へ誤って接続すると
ショートにつながる可能性がある。

不慣れな場合は、
サービスマニュアルなどの測定手順を確認する。


# 26. Wiring Modification

配線加工では、

- 適切な線径
- 適切な端子
- 適切な圧着
- 絶縁
- 防水
- ヒューズ
- 配線保護

が重要。

配線をねじってテープだけで固定するなど、
信頼性の低い接続は避ける。

振動・水・熱の影響を受けるため、
オートバイでは特に配線の固定と保護が重要。


# 27. Connectors

コネクターを外す際は、
無理に配線を引っ張らない。

確認項目：

- ロック
- 端子
- 腐食
- 変形
- 水分
- 接触状態

接触不良は、
電装トラブルの原因になる。


# 28. Electrical Safety

電装作業ではショートや発熱、
部品破損、火災などのリスクがある。

作業前に、

- イグニッションOFF
- 必要に応じてバッテリーのマイナス端子を外す
- 短絡防止
- ヒューズ容量確認
- 配線の保護
- 燃料周辺での火花防止

を行う。

特に燃料系統の近くで電装作業を行う場合は、
火花や発熱に十分注意する。


# 29. Legal and Inspection Considerations

灯火類などの電装カスタムでは、
保安基準や車検への適合が必要になる場合がある。

確認対象の例：

- ヘッドライト
- ウインカー
- テールランプ
- ブレーキランプ
- ホーン
- ミラー
- 反射器
- 補助灯

具体的な法規・基準については、
regulations/ 以下のKnowledgeを優先する。

法規が不明な場合、
「合法」と断定しない。


# 30. Knowledge Priority

電装に関する回答では、
以下の優先順位でKnowledgeを使用する。

1. 車種・世代別のメーカー資料・サービスマニュアル
2. 車種・型式別のKnowledge
3. systems/electrical.md
4. custom/electrical.md
5. safety/electrical.md
6. regulations/ 以下の法規Knowledge

車種固有の配線・電装仕様と一般論が異なる場合、
車種固有の資料を優先する。


# 31. Uncertainty Rules

以下の情報が不足している場合、
具体的な配線方法や部品適合を断定しない。

不足情報の例：

- メーカー
- 車種
- 年式
- 型式
- 世代
- 純正 / 社外
- 現在のカスタム状態

特に以下は必ず確認する：

- 配線図
- 電圧
- 極性
- ヒューズ容量
- コネクター
- 部品適合

不明な場合は、

- 確認が必要
- 車種・型式が必要
- 配線図が必要
- メーカー資料の確認が必要
- 専門店への確認を推奨

などと明示する。


# 32. Important Principle

電装トラブルでは、

「部品が壊れている」

と最初から決めつけない。

まず、

- 電源
- ヒューズ
- アース
- スイッチ
- 配線
- リレー
- コネクター

などを確認し、
回路を分けて原因を特定する。

また、
電装カスタムでは
「取り付けできるか」だけではなく、

- 電力
- 配線
- ヒューズ
- 発熱
- 防水
- 安全性
- 法規

まで考慮する。


# 33. Scope

このKnowledgeは、
オートバイ全般に共通する電装システムの
基礎・診断・カスタム・安全知識を扱う。

以下はこのファイルでは断定しない：

- 特定車種の配線色
- 特定車種の配線図
- 特定年式の電装仕様
- ヒューズ容量
- 正常電圧値
- 点火方式
- コネクター形状
- ECU / CDI / TCIの具体的仕様
- 特定部品の適合
- 保安基準の具体的数値

これらは車種・世代別Knowledge、
またはregulations/ 以下のKnowledgeを参照する。
